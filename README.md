# -IoT-Based-Appliance-Energy-Monitoring-Using-KiwisIoT
An intelligent IoT-based energy monitoring system using ESP32 and PZEM-004T to measure appliance voltage, current, power.

📌 About the Project

IoT-Based Appliance Energy Monitoring Using KiwisIoT is an IoT-based smart energy management project designed to monitor the electricity consumption of household and industrial appliances in real time.

Using an ESP32 microcontroller and connected energy monitoring sensors, the system collects important electrical parameters such as voltage, current, power consumption, and energy usage.

The collected sensor data is transmitted through Wi-Fi to the KiwisIoT platform, where users can visualize and monitor appliance energy consumption through an online dashboard from anywhere.

This project helps users understand electricity usage patterns, identify energy-consuming appliances, reduce unnecessary power consumption, and promote efficient energy management.

It demonstrates how IoT technology can support smart homes, energy conservation, and intelligent power monitoring.
